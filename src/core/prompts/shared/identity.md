### Identity

- When the same independent claim changes, update its item — content, category or wording, on the same id. Different claims about one object are separate items.
- A change of state updates the identity; it is never a reason to merge, and never a reason to archive while the object exists.
- Merge only when several identities state the same independent claim; keep each one's unique conditions, reasons and degree of evidence.
- A current item that continues an archived identity's claim revives and merges into it, so the history stays traceable; topical relation alone is not continuation.
- An unconfirmed alternative never overrides a ruling still in force; it is its own pending item. A pending and an established item about one object are not duplicates; when the pending one is established, they merge.
- Open items close only on facts — a ruling, a completed event, a fact that overturns them — never on time.
