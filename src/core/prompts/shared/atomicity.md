### Atomicity

- One item records one claim — one object, one content — that changes on its own.
- When the claim's content changes, update the original item, so that the change and its historical evidence can be traced; different independently changing claims about one object are maintained apart.
- Knowledge belongs to the project by default. Only a conclusion of global meaning — a user preference, the general environment, a general working method — is `global`; `session` holds only knowledge valid within this session alone.
