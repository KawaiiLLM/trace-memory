### Admission

- Future-use test: importance is the cost of forgetting, never the effort spent, the length of the discussion or the kind of task. Without this item, would a future agent decide wrongly, repeat work or violate a user preference?
- Knowledge carries macro understanding, not the implementation detail under it. A conclusion that must already be known when acting stays resident: a constraint, a mechanism, a path, a threshold. A value, a list or a detail that can be looked up in an artifact or a document without any guiding understanding is not resident; only the pointer to where it is found is kept.
- Do not extract an equivalent duplicate of existing knowledge, or a trivial consequence existing knowledge already yields.
