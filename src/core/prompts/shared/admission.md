### Admission

- Keep only what, if deleted, would make a future agent decide wrongly, redo finished work, violate a rule or preference, or re-investigate a settled question.
- Importance is the cost of forgetting — never the effort spent, the length of the discussion or the kind of task.
- What an artifact answers (git, the files, the package registry, one command) is not kept.
- What the pool already holds is not recorded again unless new evidence changes it.
- Over-distillation is distortion: a short-lived detail must not pose as long-lived knowledge.
- Record not only what is used now but what it replaced, and why.
