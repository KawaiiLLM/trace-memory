# Verify: update and archive

This run's operations are **update** and **archive**. The change file holds the update and archive changes that curate proposed. Nothing is applied until your file passes the check. Give every change one verdict.

For an update, look for a wrong attribution, a dropped condition or qualifier, a ruling rewritten as pending, and a paraphrased quote whose wording is the constraint. Correct a wrong rewrite with an edit that restores what the facts support.

For an archive, look for an item archived although it still holds, or archived with a successor that is not current. An archive takes only confirm or revert: revert when the evidence shows the content still holds.
